# Changelog

## 1.0.0 (2026-04-08)


### Features

* Initial release of `@nanopub/nanopub-testsuite-connector-js`, a connector for the official Nanopublication Test Suite
* `NanopubTestSuite.getLatest()` and `getAtCommit()` to download and load the suite from GitHub
* Access to transform cases, valid/invalid SIGNED and TRUSTY entries, and signing keys
